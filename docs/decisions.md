# Решения по MVP

| Тема | Решение |
|---|---|
| Что превращать в точки | Выбор пользователя: всё точками (по умолчанию) / основной контур точками, детали линиями |
| Нумерация нескольких линий | Выбор пользователя: сквозная с «прыжками» (по умолчанию) / отдельные серии |
| Сложность | Ползунок «малыш / школьник / взрослый» (~20 / 60 / 150+ точек) |
| Подписи | Цифры или математические примеры (выбор пользователя), в MVP |
| Ручной редактор точек | v2 |
| Формат результата | PDF A4 (+ лист-ответ); остальные форматы в v2 |
| Языки | RU + EN |
| Хостинг | VPS, docker compose |
| Очередь | Redis + BullMQ (Nest `@nestjs/bullmq`, Python `bullmq`) |
| Алгоритм | Python + OpenCV + scikit-image, горизонтальное масштабирование воркеров |
| Донаты | CloudTips (основной для РФ), опционально Boosty; Ko-fi для EN — ссылки в конфиге |
| Маскот | Dottie — дружелюбная точка с глазками |
