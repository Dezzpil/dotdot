# Решения по MVP

| Тема | Решение |
|---|---|
| Что превращать в точки | Выбор пользователя: всё точками / только контур (детали линиями). По умолчанию: «малыш» — только контур, «школьник» и «взрослый» — всё точками |
| Нумерация нескольких линий | Выбор пользователя: сквозная с «прыжками» (по умолчанию) / отдельные серии |
| Сложность | Ползунок «малыш / школьник / взрослый» (~20 / 60 / 150+ точек) |
| Подписи | Цифры или математические примеры (выбор пользователя), в MVP |
| Ручной редактор точек | v2 |
| Формат результата | PDF A4 (+ лист-ответ); остальные форматы в v2 |
| Языки | RU + EN |
| Хостинг | VPS, docker compose |
| Очередь | Redis + BullMQ (Nest `@nestjs/bullmq`, Python `bullmq`) |
| Алгоритм | Python + OpenCV + scikit-image, горизонтальное масштабирование воркеров |
| Донаты | CloudTips (основной для РФ), опционально Boosty; Ko-fi для EN — ссылки в конфиге |
| Маскот | Dottie — дружелюбная точка с глазками |

## Алгоритм v0 — результаты на Among Us

| Режим | Точек | Время |
|---|---|---|
| малыш, только контур | 48 | ~0,45 с |
| школьник, всё точками | 128 | ~0,55 с |
| взрослый, всё точками | 255 | ~0,9 с |

Примеры: [docs/samples](samples).

## Алгоритм v1 — меньше отрывов, чище подписи

| Уровень | Отрывов v0 → v1 | Двусмысленных подписей v0 → v1 |
|---|---|---|
| малыш | 16 → 9 | 0 → 0 |
| школьник | 22 → 15 | 2 → 0 |
| школьник, примеры | 22 → 15 | 14 → 0 |
| взрослый, примеры | 23 → 19 | — → 1 |
| взрослый | 23 → 19 | 18 → 1 |

Наложений подписей друг на друга, на точки и на линии — 0 во всех режимах.

## Старт нумерации

Точка 1 всегда на макушке рисунка. Замкнутая линия просто поворачивается к верхней точке (бесплатно), открытая разрезается в ней на две ветки, обе начинаются с точки 1 (+1 отрыв).

## API и очередь

| Тема | Решение |
|---|---|
| API | NestJS 12 (только ESM), `@nestjs/bullmq`, Node.js 22 (нужен зависимостям Nest 12); тесты — Vitest + SWC |
| Связь API ↔ воркер | BullMQ поверх Redis: задача `{id, input, options}`, результат — пути к файлам; статусы через QueueEvents |
| Статус в браузере | SSE `/api/jobs/:id/events` (один поток QueueEvents на реплику), запасной вариант — опрос `GET /api/jobs/:id` |
| Хранилище файлов | Общий Docker-том `/data`, TTL 24 ч. MinIO не берём: бесплатная версия больше не развивается, репозиторий в архиве. Интерфейс хранилища маленький — S3-драйвер (Garage, SeaweedFS, облако) можно добавить позже |
| Устойчивость к наплыву | Реплики API за Caddy, воркеры по одному ядру, лимиты по IP в Redis, `429 BUSY` при длинной очереди, кеш по хешу картинки и параметров, Redis `noeviction` + AOF |
| Ошибки | Единый формат `{error: {code, message}}`, тексты для людей — в веб-интерфейсе |
